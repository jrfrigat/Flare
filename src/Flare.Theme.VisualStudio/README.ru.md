# Flare.Theme.VisualStudio

Тема в духе Visual Studio (2022/2026), светлая и темная, для библиотеки компонентов
[Flare](https://github.com/jrfrigat/Flare) на Blazor.

```sh
dotnet add package Flare.Theme.VisualStudio
```

```csharp
// как тема по умолчанию...
builder.Services.AddFlare(opts => opts.DefaultTheme = new VisualStudioTheme());
// ...или зарегистрировать и переключать во время работы:
builder.Services.AddFlareTheme(new VisualStudioTheme());
// await ThemeService.SetThemeAsync("visualstudio");
```

## Что тема оформляет

Тема оформляет базовый набор компонентов Flare - кнопки, поля, меню, деревья, вкладки, диалоги,
таблицы. Она не оформляет необязательные компоненты оболочки приложения и не объявляет их токены.
Приложение, которому нужна похожая на Visual Studio IDE-оболочка, задает эти токены в своей области;
пакет оболочки предоставляет дефолты от базовых ролей.

Кнопки, поля, флажки и таблицы - это обычный набор компонентов Flare в токенах этой темы; VS их не
переименовывает.

## Что тема меняет помимо цвета

- **Плотность по умолчанию.** Типографическая шкала и высоты элементов настроены под IDE, а не под палец.
- **Прямые углы и штрихи в 1px.** Шкала формы почти везде близка к нулю.
- **Выделение - плоская заливка, а не тональная пленка**: та же модель дискретных состояний, что и у
  Fluent, поэтому тема задает свои токены слоя состояния, а не полагается на значение из Material.

## Роли оболочки VS 2026

Темная оболочка следует измеренной палитре Visual Studio 2026: меню/заголовок `#1C1C1C`, командная
панель и полоса вкладок документов `#262626`, активная вкладка и окна инструментов `#282828`,
редактор `#1E1E1E`, хлебные крошки `#2B2B2B`, нижняя панель `#1C1C1C`, строка состояния `#141414`,
разделители `#0E0E0E`/`#3D3D3D`, контуры `#454545`, меню `#2C2C2C`, наведение `#383838` и акцент
`#9184EE`, нарисованный линиями фокуса в 1px. Светлая оболочка сохраняет прежние значения.

Поверхности вынесены в переменные темы, поэтому хост может покрасить область оболочки, не
переопределяя общую цветовую роль:

| Переменная | Область |
| :-- | :-- |
| `--flare-vs-chrome-title-bar` | Меню и заголовок |
| `--flare-vs-chrome-command-bar` | Командная панель |
| `--flare-vs-chrome-command-well` / `--flare-vs-chrome-command-well-border` | Поле управления командной панели и его рамка |
| `--flare-vs-chrome-tab-strip` | Полоса вкладок документов |
| `--flare-vs-chrome-tab-active` | Активная вкладка документа |
| `--flare-vs-chrome-editor` | Редактор |
| `--flare-vs-chrome-breadcrumb` | Полоса хлебных крошек |
| `--flare-vs-chrome-breadcrumb-edge` | Кромки хлебных крошек и область действий |
| `--flare-vs-chrome-tool-window` | Окно инструментов |
| `--flare-vs-chrome-tool-tab` | Полоса вкладок и заголовок инструмента |
| `--flare-vs-chrome-field` | Поле поиска инструмента и поле ввода |
| `--flare-vs-chrome-bottom-panel` | Полоса вкладок нижней панели |
| `--flare-vs-chrome-bottom-tab-underline` | Подчеркивание вкладки нижней панели |
| `--flare-vs-chrome-status-bar` | Строка состояния |
| `--flare-vs-chrome-bar-edge` / `--flare-vs-chrome-divider` | Кромка панели и разделители |
| `--flare-vs-chrome-outline` | Контуры элементов |
| `--flare-vs-chrome-menu` / `--flare-vs-chrome-hover` | Панель меню и наведение |
| `--flare-vs-chrome-accent` | Акцент фокуса и выделения |
| `--flare-vs-chrome-scrollbar-thumb` / `--flare-vs-chrome-scrollbar-track` | Полоса прокрутки |

Необязательные пакеты оболочки приложения владеют своими токенами и их базовыми дефолтами. Эта тема
их не объявляет: приложение, которому нужны измеренные поверхности IDE, задает эти токены в своей
области.

## Метрики компонентов VS 2026

- **Поля.** Колодец с заливкой `#353535`, штрихом 1px `#454545`, углами 4px и отступом текста 8px.
  Шкала Xs..Xl - 24/24/28/36/44px, как у кнопок: решение Flare (2026-11-22), заменяющее измеренную
  лестницу 20/22/23/26/30px.
- **Кнопки.** 24px квадрат, глиф 16px, углы 4px.
- **Фокус.** Одна линия акцента `#9184EE` толщиной 1px у полей, кнопок, флажков и переключателей;
  без внешнего свечения.
- **Полосы прокрутки.** Квадратный ползунок 2px `#9D9D9D` на поверхности панели. Chromium и WebView2
  рисуют его через путь WebKit, который тема оставляет включенным; Firefox сохраняет свою полосу.
- **Панели.** Углы 6px у выпадающих списков и поповеров; поле поиска инструмента получает те же 6px
  через `--flare-vs-chrome-search-radius`.

## Типографика и иконки VS 2026

- **Текст.** Подписи меню и дерева остаются 13px (BodyLarge); основной текст использует 12px
  BodyMedium темы.
- **Иконки и строки.** Строки дерева высотой 24px; иконки дерева и кнопок - 16px, а у раскрывателя
  остается цель 24px вокруг глифа.
