# Flare.Components.Kanban

Компонент канбан-доски (перетаскиваемые колонки и карточки) для библиотеки компонентов
[Flare](https://github.com/jrfrigat/Flare) на Blazor. Дополнительный пакет, расширяющий `Flare.Components`.

```sh
dotnet add package Flare.Components.Kanban
```

Требует `Flare.Components` и пакет `Flare.Theme.*`. Используйте `<FlareKanban>`, когда Flare уже настроен
(см. readme пакета `Flare.Components`).

Репозиторий и документация: https://github.com/jrfrigat/Flare  -  лицензия MIT.
