# Flare.Components.RichTextEditor

Компонент редактора форматированного текста (WYSIWYG) для библиотеки компонентов
[Flare](https://github.com/jrfrigat/Flare) на Blazor. Дополнительный пакет, расширяющий `Flare.Components`.

```sh
dotnet add package Flare.Components.RichTextEditor
```

Требует `Flare.Components` и пакет `Flare.Theme.*`. Используйте `<FlareRichTextEditor>`, когда Flare уже
настроен (см. readme пакета `Flare.Components`).

Репозиторий и документация: https://github.com/jrfrigat/Flare  -  лицензия MIT.
