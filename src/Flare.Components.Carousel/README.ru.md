# Flare.Components.Carousel

Компонент карусели / слайдшоу для библиотеки компонентов [Flare](https://github.com/jrfrigat/Flare) на Blazor.
Дополнительный пакет, расширяющий `Flare.Components`.

```sh
dotnet add package Flare.Components.Carousel
```

Требует `Flare.Components` и пакет `Flare.Theme.*`. Используйте `<FlareCarousel>`, когда Flare уже настроен
(см. readme пакета `Flare.Components`).

Репозиторий и документация: https://github.com/jrfrigat/Flare  -  лицензия MIT.
