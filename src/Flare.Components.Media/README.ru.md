# Flare.Components.Media

Медиа-компоненты для библиотеки компонентов [Flare](https://github.com/jrfrigat/Flare) на Blazor:
`FlareVideoPlayer` и `FlareSignaturePad`. Дополнительный пакет, расширяющий `Flare.Components`.

Загрузка файлов живет в `Flare.Components` с версии 0.8.0 - она принимает любой файл, поэтому
медиа-компонентом никогда не была; ради нее этот пакет больше не нужен.

```sh
dotnet add package Flare.Components.Media
```

Требует `Flare.Components` и пакет `Flare.Theme.*` (базовая настройка - в readme пакета `Flare.Components`).

Репозиторий и документация: https://github.com/jrfrigat/Flare  -  лицензия MIT.
