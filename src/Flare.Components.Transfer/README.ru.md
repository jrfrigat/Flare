# Flare.Components.Transfer

Компонент переноса элементов между двумя списками (dual list box) для библиотеки компонентов
[Flare](https://github.com/jrfrigat/Flare) на Blazor. Дополнительный пакет, расширяющий `Flare.Components`.

```sh
dotnet add package Flare.Components.Transfer
```

Требует `Flare.Components` и пакет `Flare.Theme.*`. Используйте `<FlareTransfer>`, когда Flare уже настроен
(см. readme пакета `Flare.Components`).

Репозиторий и документация: https://github.com/jrfrigat/Flare  -  лицензия MIT.
